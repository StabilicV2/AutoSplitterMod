# AutoSplitterMod

This is a mod for Minecraft 1.16.1 which connects to the LiveSplit application to execute splits on in game events, toggleable through game settings.
This mod has not been approved by the official speedrunning community, use at own risk in rsg runs. This mod does not work in MSCR Ranked due to it not being whitelisted. However to follow regulations the mod does not alter any game properties, and only listens for game events to relay them to the LiveSplit application, additionally the Fabric API is not used to further align with the current regulations
